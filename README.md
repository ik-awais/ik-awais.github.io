## 🔍 Overview

This portfolio started as a single static HTML file and evolved into a full Hugo-based site with blog support, custom theming, animated UI elements, and production-grade form handling. The entire design, architecture, and codebase were built iteratively — solving real problems at each stage including broken contact forms, CSS conflicts, Hugo template rendering issues, and deployment pipeline configuration.

It currently hosts **three AI/ML projects** and **four blog posts**, with more being added regularly.

**Key highlights:**
- Zero CSS framework — every style hand-written with CSS Variables
- Zero JS framework — vanilla JS with `requestAnimationFrame`, `IntersectionObserver`, and AJAX
- Automated CI/CD — push to `main` branch → live in ~90 seconds
- Production-grade contact form security with honeypot, rate limiting, and disposable email blocking
- Deployed from `main` branch via GitHub Actions (migrated from `portfolio` branch)

## ✨ Features

### 🏠 Homepage
- **Hero section** with animated orbital rings and floating center dot
- **Scrolling tech stack** — dual-row infinite scroll with hover scale effect (Devicon CDN)
- **Animated stat counters** — count up on scroll with IntersectionObserver
- **Featured project cards** — pulled dynamically from `content/projects/` via Hugo's `range` function
- **Working contact form** — Formspree integration via AJAX (FormData), with full validation

### 🌙 Dark / Light Theme
- **Toggle button** in navbar (☽ / ☀ icons)
- **CSS Variables** swap the entire palette — no duplicate stylesheets
- **LocalStorage persistence** — theme choice survives page reloads and navigation
- Dark: `#060610` background, `#7c3aed` accent, `#e0e0ec` text
- Light: `#f0f2f5` background (cool grey, GitHub-style), `#7c3aed` accent, `#111827` text
- All elements adapt: cards, nav, code blocks, form inputs, borders, footer

### 🖱️ Custom Cursor
- Small dot follows mouse position instantly
- Larger ring follows with spring-lag animation (`0.12` lerp factor)
- Magnetic hover effect on interactive elements (buttons, links, cards)
- Automatically hidden on touch devices via `(hover: none)` and `(pointer: coarse)` media queries

### 📝 Blog
- **Hugo-native Table of Contents** — auto-generated from `## h2` and `### h3` headings at build time
- **Sticky ToC sidebar** — fixed on the right side, scrolls with the reader
- **Active section highlighting** — JS IntersectionObserver tracks which heading is in view
- **Responsive** — ToC hides on screens < 1024px
- **Prose styling** — `h2` with bottom borders, `h3` in accent color, dark code blocks in both themes

### 🔒 Contact Form Security
- **Deep email validation** — RFC 5321 format checking, blocks consecutive dots, validates TLD length (2–12 chars)
- **Disposable email blocking** — rejects 50+ known throwaway services (Mailinator, Guerrilla Mail, YOPmail, TrashMail, etc.)
- **Honeypot field** — hidden input invisible to real users, catches bots that auto-fill all fields
- **Client-side rate limiting** — max 3 submissions per session, minimum 60 seconds between sends
- **Form UX** — inputs clear after successful send, button shows "✓ Sent" in green, resets after 4 seconds

### 📱 Responsive Design
- **3 breakpoints**: 1024px (hide ToC), 768px (mobile layout), 400px (very small phones)
- Mobile: single column, compressed padding, full-width buttons
- Nav collapses appropriately per breakpoint

### 🧭 Navigation
- Scroll-aware navbar — background becomes solid on scroll via `scrollY > 50` detection
- LinkedIn and Upwork (Hire Me) buttons in nav
- Theme toggle integrated into nav

## 🛣️ Development Journey

Key technical problems solved throughout the build:

1. **Migrated from raw HTML to Hugo** — rebuilt a single `index.html` into a proper Hugo content/layout structure with blog support.

2. **Fixed Hugo template directory** — `layouts/default/` → `layouts/_default/` (missing underscore caused Hugo to find no templates).

3. **Resolved CSS/JS not loading** — `baseURL` in `hugo.toml` was set to a production URL, breaking asset paths in local dev. Fixed with `baseURL = "/"` locally.

4. **Blog content invisibility bug** — `.reveal` class on `.single-body` set `opacity: 0`. IntersectionObserver missed the trigger since content was already in viewport on load. Removed `.reveal` and added `opacity: 1 !important`.

5. **Table of Contents — JS approach failed** — `DOMContentLoaded` fired before the inline script registered. Switched to Hugo's native `{{ .TableOfContents }}` — zero JS scraping needed.

6. **Formspree reCAPTCHA conflict** — reCAPTCHA blocked all AJAX submissions on free plan. Disabled it; replaced with honeypot + email validation + rate limiting.

7. **Migrated deploy branch from `portfolio` to `main`** — merged branches, resolved all conflicts using `git checkout --theirs .`, force-synced missing layout files with `git checkout portfolio -- .`, updated `deploy.yml` trigger from `portfolio` → `main`, and switched GitHub Pages source from "Deploy from a branch" to "GitHub Actions".

8. **GitHub Pages deployment permissions** — deploy branch wasn't authorized in the `github-pages` environment. Fixed in Settings → Environments → github-pages.

9. **Light theme readability** — warm off-white `#f5f5ef` looked washed out. Rebuilt to cool grey `#f0f2f5` matching GitHub/VS Code light theme conventions.

10. **Word count on project cards** — replaced raw `{{ .WordCount }}` output with `{{ .Date.Format "Jan 2006" }}`.

## 🚢 Deployment

Deployment is fully automated via GitHub Actions, triggered on every push to `main`.

### How It Works

1. Push to the `main` branch
2. GitHub Actions triggers `.github/workflows/deploy.yml`
3. Workflow checks out the repo and sets up Hugo v0.154.5 extended
4. Runs `hugo --minify --baseURL "${{ steps.pages.outputs.base_url }}/"`
5. Uploads `public/` as a GitHub Pages artifact
6. Deploys to GitHub Pages
7. Live at [https://ik-awais.github.io/](https://ik-awais.github.io/) within ~90 seconds

### Current `deploy.yml`

```yaml
name: Deploy Hugo to GitHub Pages

on:
  push:
    branches:
      - main
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Pages Configuration
        id: pages
        uses: actions/configure-pages@v5

      - name: Setup Hugo Extended
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: '0.154.5'
          extended: true

      - name: Build Static Assets
        run: hugo --minify --baseURL "${{ steps.pages.outputs.base_url }}/"
        env:
          HUGO_PARAMS_FORMSPREEEID: ${{ secrets.FORMSPREE_ID }}

      - name: Upload Build Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./public

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy Compiled Site
        id: deployment
        uses: actions/deploy-pages@v4
```

### One-Time Setup Required

- Repo **Settings → Pages → Source**: set to `GitHub Actions`
- Repo **Settings → Environments → github-pages**: add `main` as an allowed deployment branch
- **Formspree**: create a form at [formspree.io](https://formspree.io) and store the ID as a secret named `FORMSPREE_ID` in repo Settings → Secrets

## 🔐 Security

| Layer | Implementation |
|---|---|
| Email validation | RFC 5321 format, TLD check, domain segment validation |
| Disposable email blocking | 50+ providers blocked (Mailinator, YOPmail, etc.) |
| Bot honeypot | Hidden form field, invisible to humans, filled by auto-fill bots |
| Rate limiting | 3 submissions/session, 60s cooldown between sends |
| CSP headers | `static/_headers` with Content-Security-Policy, X-Frame-Options, X-Content-Type-Options |
| Source protection | Static site — no server, no database, minimal attack surface |

> **Note:** GitHub Pages does not natively apply `_headers` files (Netlify/Cloudflare Pages feature). The file is included for portability — headers activate automatically if the site moves to either platform.

## 🔧 Troubleshooting

| Issue | Cause | Fix |
|---|---|---|
| CSS/JS not loading locally | `baseURL` set to production URL in `hugo.toml` | Set `baseURL = "/"` for local dev |
| Blog content invisible | `.reveal` class on `.single-body` sets `opacity: 0` | Remove `.reveal` from the content wrapper |
| ToC sidebar empty | JS ran before DOM was ready | Use Hugo's native `{{ .TableOfContents }}` |
| Formspree submissions rejected | reCAPTCHA enabled on free plan blocks AJAX | Disable reCAPTCHA in Formspree dashboard |
| Deploy fails on GitHub Actions | Branch not in environment protection allowlist | Add `main` in Settings → Environments → github-pages |
| Old content showing after push | GitHub Pages cache | `git commit --allow-empty -m "force rebuild" && git push` |
| Theme toggle not persisting | localStorage key mismatch | Confirm `main.js` uses `theme` as the storage key |
| Layout broken after branch switch | GitHub Actions still pointing to old branch | Update `deploy.yml` trigger branch to `main` |
| Missing files after merge | `git checkout --theirs` only resolves conflicts, skips unique files | Run `git checkout portfolio -- .` to force-sync all files |
