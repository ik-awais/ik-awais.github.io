A Retrieval-Augmented Generation (RAG) system that allows users to upload PDF, DOCX, and TXT files and ask questions using natural language.

The system performs semantic search across documents using embeddings and returns context-aware answers generated by a large language model.

Key capabilities include:

- Semantic search using vector embeddings
- Multi-document querying
- Conversational memory for follow-up questions
- Source citation highlighting
- Full document summarization
- Model switching from UI

Architecture:

Document → Chunking → Embeddings → Vector Store → Retrieval → LLM Response
