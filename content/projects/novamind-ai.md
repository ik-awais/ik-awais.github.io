## Overview

NovaMind AI is a full-stack AI research engine designed to combine web search, document-grounded retrieval, and language-model-driven research into a unified workflow.

The system brings together multiple search providers and retrieval infrastructure to produce streamed answers supported by citations.

## Core Capabilities

- Multi-provider web search.
- Document-grounded retrieval.
- Retrieval-Augmented Generation.
- Streamed responses with citations.
- Vector retrieval using pgvector.
- Containerized application infrastructure.

## Technology Stack

- Next.js
- Retrieval-Augmented Generation
- PostgreSQL / pgvector
- Tavily
- Brave Search
- Firecrawl
- Docker Compose
- JSON Web Tokens (JWT)

## Engineering Focus

The project explores how multiple information sources and retrieval mechanisms can work together in a single research-oriented application.

Its central focus is combining web discovery with document-grounded information retrieval while maintaining source traceability.
